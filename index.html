◆ Project Overview

The Spam Detection Pipeline

A complete machine learning workflow from raw text to intelligent classification, designed with precision and transparency.

📧

Dataset

SMS Spam Collection Dataset from UCI Machine Learning Repository. Contains 5,574 messages labeled as ham (legitimate) or spam (unsolicited). The dataset is slightly imbalanced with ~13% spam messages, making recall optimization critical.

🎯

Objective

Build a robust NLP binary classifier that accurately distinguishes spam from ham emails using text preprocessing, TF-IDF feature extraction, and machine learning algorithms. Special focus on high recall to ensure no malicious spam slips through.

⚡

Tech Stack

Python - pandas, numpy for data manipulation
NLTK - tokenization, stemming, stopword removal
scikit-learn - TF-IDF, Naive Bayes, Logistic Regression, SVM
matplotlib/seaborn - EDA visualizations
WordCloud - text pattern visualization

🔒

Why Recall Matters

In spam detection, a False Negative (spam classified as ham) is far more dangerous than a False Positive. Missing a phishing email can lead to identity theft, financial loss, or data breaches. We optimize for recall >95% while maintaining precision balance.

◆ Methodology

Crystal-Clear Pipeline

Six systematic steps from raw text to intelligent predictions

1
📊

Exploratory Data Analysis

Dataset inspection, class distribution analysis, message length statistics, and word count comparisons between ham and spam categories. Visualized with crystal-themed bar charts and box plots.

2
🧹

Text Preprocessing

Lowercase conversion → Punctuation removal → Number stripping → Tokenization → Stopword removal → Porter Stemming. Transforms raw text into clean, normalized tokens ready for vectorization.

3
🔢

TF-IDF Vectorization

Converts text into numerical features using Term Frequency-Inverse Document Frequency. Captures word importance relative to the corpus. Uses unigrams and bigrams (ngram_range=1,2) with 3,000 max features for optimal performance.

4
🤖

Model Training

Three classifiers trained on 80% stratified split: Multinomial Naive Bayes (probabilistic, fast), Logistic Regression (linear, interpretable), SVM (maximum margin, robust).

5
📈

Evaluation

Comprehensive metrics: Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC curves. Special attention to recall scores to minimize missed spam. Cross-model comparison table for transparent selection.

6
☁️

WordCloud Analysis

Visual frequency analysis of spam vs ham vocabulary. Spam clouds reveal trigger words like "free", "win", "urgent", "call now". Ham clouds show natural conversational patterns and personal terms.
